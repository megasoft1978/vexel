Implementation

  document-unique `vexel-object-N` ID to an SVG graphics root that lacks one.

  returns `duplicate_id` before editing. `<defs>` and metadata roots are left
  without generated IDs.

  stable through redo. Canvas, text/path insertion, and MCP share these APIs;
  MCP returns the assigned value as `elementId`.
