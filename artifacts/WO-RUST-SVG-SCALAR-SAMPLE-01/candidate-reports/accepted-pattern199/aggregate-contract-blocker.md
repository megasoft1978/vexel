# Protected shared contract prevents revision 2 completion

`rust/crates/vexel-scene/src/raster_job.rs:223` (`RasterJob::check_pool`) adds all live Dash and Grid pool bytes, subtracts only the replaced handle's current capacity, adds the requested buffer capacity, and rejects above 16 MiB. Both generations of a staged cache remain live, so this is an extra limit on cache replacement. `check_grid` likewise counts old and staged grid capacities globally. These are logical limits, not the ChargeLedger physical old/new overlap admission.

The independent review's absent-cap premise does not describe this current shared source: it already enforces a combined Dash+Grid cap, but across the entire job. The new owned CacheCapacity guard enforces the requested per-cache cap before reserves and verifies actual capacities after them. It cannot remove the stricter shared policy.

Exact public reproducer: `shared_pool_currently_blocks_valid_near_cap_rebuild_without_losing_old_cache` creates two admitted fixture shapes (157034 and 1 edges), builds an exactly 16,777,216-byte cache, then twice attempts its replacement under a 256 MiB ChargeLedger. Each fails with `Limit(DashCache), offset 0` at the first shape payload reserve. Old cache handles, grid contents and payload bytes remain usable. Allocation history and peak remain exactly unchanged because rejection precedes physical allocation. This passing blocker reproducer must become a success/overlap proof after the shared contract is repaired.

Using Scratch pool buffers cannot preserve the accepted interface: `RasterJob::dash_view`, scratch role validation and composition require Dash for shape/segment/join buffers and Grid for cells/references. Pool identity and pool counters are private; no public transaction, cache generation, detach/restore or role-transfer operation exists. Releasing or clearing the old cache first would violate rollback. Copying into unmetered Vecs would violate ownership/admission and still cannot restore the required handles. No workaround was implemented.
