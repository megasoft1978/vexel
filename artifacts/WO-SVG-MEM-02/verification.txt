  records and a linear-gradient stroke has exactly one mapped record.

Storage estimate (static size arithmetic, not process RSS)
- `sizeof(svg_shape_paint)` is 272 bytes; a stroke shape-to-record index is 4
  bytes. At 65,536 shapes, the former dense array reserved 17,825,792 bytes
  whenever any non-solid stroke appeared. With one non-default stroke, the
  sparse representation reserves a 262,144-byte index map and an eight-record
  initial table (2,176 bytes), about 17,561,472 bytes less. Documents in which
  most shapes have non-default strokes still require corresponding records;
  no corpus RSS or throughput result is claimed.

Limitations
- Sparse records reduce memory when non-default strokes are uncommon. They do
  not reduce paint-record count when every shape has a distinct non-default
  stroke. The synthetic Inkscape T2 shape ceiling remains; record sharing,
  other per-shape metadata, measured peak RSS, and a separately scoped limit
  decision remain future work.
