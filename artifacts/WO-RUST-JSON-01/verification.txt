Public API: `JsonDocument::{parse,parse_owned,source,tokens,root,token,object_get,
array_get,raw_token,decoded_string,string_equals,uint,bool}`; `JsonType`,
`JsonToken`, `JsonError`; `JsonBuffer::{new,as_bytes,len,is_empty,limit,append,
append_within,literal,quoted,raw_token}`; `JsonBufferError`; `MAX_BYTES`,
`MAX_DEPTH`, `MAX_TOKENS`.

Adaptations: Rust ownership/Drop replaces explicit document and buffer destroy;
`Option<usize>` replaces the no-token sentinel; accessors return owned/borrowed
Rust values instead of output pointers and capacity pairs. `Cow` permits either
borrowed immutable bytes or owned source bytes while tokens keep numeric spans.
The legacy aliasing append is represented by checked `append_within` offsets.
Buffer failures are typed and append/quoted operations leave existing content
unchanged. See parity-map.json for every C symbol.

resource handling, Tasks/bridge behavior, application integration, and broad
product acceptance remain outside WO-RUST-JSON-01. Coordinator-owned manifests,
shared state, and ledgers were not edited. No dependencies, unsafe code, network,
or external package installation used.
