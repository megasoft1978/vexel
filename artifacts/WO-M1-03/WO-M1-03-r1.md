# Goal
Make frame stepping and JSONL event replay produce identical native Metal readbacks and placeholder screenshots across repeated runs.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/research-r4/05-revised-roadmap.md`, `docs/ui-test-driver.md`, `app/test_driver/README.md`, `src/platform/platform_metal.h`, `src/platform/platform_window.h`, `src/raster/README.md`.
- Relevant ADRs: macOS-only, C17, deterministic-output decisions in `docs/adr/`.
- Frozen tests/oracles: do not modify `tests/oracle/**`, `tests/golden/**`, `bench/corpus/**`, or existing baselines.
- No external code or network access.

# Existing contracts and invariants
- C17 is the application interface; Cocoa/Metal internals remain under `src/platform/macos/`.
- Frame advancement is explicit and deterministic; no sleeps or wall-clock synchronization.
- AppKit and Metal lifecycle calls run on the main thread. Readback remains byte-exact for the M1-02 scalar tile.
- Replay input remains bounded JSONL and uses the existing UI-driver schema; preserve M1-01/02 lifecycle and dimension limits.
- Apple Silicon macOS 13+ only; no other OS stubs, third-party dependencies, or renderer claims.

# Required implementation
1. Add a repeat-replay mode for a fixed JSONL scenario that records virtual frame steps, normalized event order, screenshot hashes, and output hashes.
2. Run the same scenario 20 times in fresh output directories and fail on any event-order or artifact-hash mismatch.
3. Add native frame-step replay that submits the same fixed tile sequence 20 times through Metal, waits for command completion with a bounded timeout (no sleeps), and confirms exact readback and stable frame hashes.
4. Record successful replay counts, hashes, Release binary size, and smoke elapsed time. Update the `docs/PERF.md` milestone table with measured size and replay latency; do not claim SVG throughput or RSS.
5. Document repeat invocation, hash comparison, virtual clock behavior, synchronization, and limitations.
