API and diagnostic notes:
  - Attribute names and values are checked spans into immutable original source; error offsets
    are absolute byte offsets. Transform-node parse errors use the transform value start, and
    parent-composition errors use the element-name start, matching the C boundary behavior.
  - parse_viewbox reports malformed/range-invalid data as a viewport error at the viewBox value
    start. Invalid preserveAspectRatio reports unsupported at the failing token byte.
  - parse_preserve_aspect rejects source slices over 16 MiB with InvalidArgument at byte 0.
    Numeric/aspect whitespace is exactly space, tab, CR and LF; form feed is not whitespace.
  - `AttributeList` is capped at 16 MiB source and 256 attributes; number lists cap at 64
    values and use fallible reservation. No dependency, unsafe code, or C shim was added.
  - rustfmt/clippy were unavailable per work-order environment and were not run. No C suite,
    full workspace suite, UI/E2E, corpus, or performance campaign was run or claimed.
