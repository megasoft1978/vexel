# Candidate result

Implemented the complete owned selection and allocation-query scope against accepted scene APIs. Selection uses generation-checked `SceneView::shape_id(index)`, including zero-edge records. Bounds/source queries and hit testing retain controlled work charging and cancellation. The port preserves reverse painter order, fill rules, clip calls, inverse-space stroke distance, tolerance scaling, source specificity and append-time source assignment. Real sealed-graph fixtures exercise the accepted path, animation and lexical APIs.

Allocation capacities are held in opaque `TrackedBuffer`s. The tracker cap applies to initial leases and replacement overlap; replacements require the owning tracker/job, preserve old values on budget or physical-reserve failure, admit actual capacity before publication, and release old capacity after dropping its storage. Tests cover the previous cap bypass, old/new overlap peak and cleanup, same-source wrong-ledger, wrong source/scope, stale and duplicate release, budget rejection and arithmetic overflow. The source/job identity probe uses a shared zero-byte lease because `ChargeLedger` has no public identity accessor.

**Shared API limitation:** `ChargeLedger` has no transactional reservation or history rollback. To preserve history when `try_reserve_exact` physically fails, `reserve_table` preflights `available()` under its exclusive mutable ledger borrow, then admits actual capacity after successful physical reserve and before publishing. Strict ledger lease admission before allocation and unchanged allocation history after a physical allocation failure cannot both be guaranteed with the accepted shared API. Coordinator-owned shared API work is required to close that contract gap.

The assigned pure assertions and focused tests pass. Original mixed `measure_allocation_source` input/assertions remain preserved but unexecuted pending concrete decoder/reference-index, clip-copy and raster-output composition. Full renderer/app/runtime/release/authentic MCP demo and product QA remain later gates. This is a candidate, not an accepted integration result.
