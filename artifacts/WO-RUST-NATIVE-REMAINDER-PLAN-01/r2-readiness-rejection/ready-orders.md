# Proposed complete native Rust implementation orders

These are planning scopes only. All production ownership, interfaces and tests remain unchanged until separate orders are accepted. Build `vexel-platform-apple` native implementations privately; public outputs are owned Rust values. No `lib.rs`, workspace manifest, lockfile, shared interface, or ledger edits belong to workers. Coordinator alone stages shared module exports/manifests/locks and freeze records after each gate. The accepted window source order supplies prerequisite APIs; it does not establish native runtime behavior.

## 0. NATIVE-MEDIA-TEXT

**Effort:** Luna Medium; CoreText shaping portion High. **Dependencies:** registered platform-owned DTO contract (coordinator gate below), existing `vexel-platform-apple` MainThread and `guard_native_call`; selected `objc2-core-text`, `objc2-core-graphics`, Foundation and ImageIO. Apple crate has no scene/UI/base dependency and does not gain one. **Owned source paths:** new `rust/crates/vexel-platform-apple/src/native_media/{text.rs,image.rs,gif.rs,tests.rs}` after coordinator registers module roots. A later root composition adapter in `rust/app/vexel-app/src/media_adapter.rs` implements `vexel_scene::MediaProvider`; it depends on scene and platform after coordinator workspace/dependency gate. **Contract:** platform DTOs `NativeTextRequest`, `NativeTextLayout { glyphs, commands, metrics }`, `NativeImage { rgba, byte_count, row_stride, width, height }`, `NativeAnimationFrame`, `NativeEncodedBytes`, and `NativeMediaError`; DTOs own results, borrow inputs only during call. CoreText returns actual shaped glyph advances and owned y-up outline commands; ImageIO returns actual top-row premultiplied RGBA static pixels; root adapter maps `WorkControl` and validates scene output. Root helper implements strict bounded PNG data URI and bilinear scaling; native GIF accepts borrowed frames during call and returns owned bytes. Preserve 64KiB text, 16,384 native glyph, 262,144 path segment, 32 families × 256 bytes, 32MiB input, 64M pixels, 16,384 image axis, exact PNG data URI prefix/44,739,266-byte URI bound, single-frame GIF decode/reject animation, 120 GIF frames, 4096 frame axis, 32M total frame pixels, 128MiB encoded output, fps ≤60 and all frame validation from source. Honor Rust scene's 65,536 output-glyph cap and 262,144 commands; stricter native 16,384 glyph limit applies. No substitute glyphs/pixels, filesystem or network reads. **Tests assigned:** exact canonical `platform_media_test.c` cases/assertion records and `media_probe.c` cases from `native-inventory.json` belong only to `NATIVE_MEDIA_TEXT`; fixture generator and README vectors are inputs/spec, not duplicate owners. Preserve malformed/truncated, limit edges, premultiplication/stride/scale, shaping/anchors/family/style/weights/color-only unsupported, URI 200k campaign, cancellation and owned result lifetime.

## 1. NATIVE-UI-TEXT-PREFERENCES

**Effort:** Luna Medium. **Dependencies:** order 0 for shared text shaping; current `vexel-ui::TextDraw` exact callback and `WidgetCanvas`; selected AppKit/CoreText/CoreGraphics/Foundation. **Owned paths:** `native_text_ui/{draw.rs,preferences.rs,cache.rs,tests.rs}` only. Provide a main-thread-owned draw adapter that installs the actual callback and paints actual CoreText coverage into caller RGBA after checking dimensions, stride, buffer capacity and clip. No silent fallback if adapter is absent; return a surfaced draw failure. Implement observable current/extended preferences, app active state, UI scale accepted values 100/110/120/125/150/175/200 for menu where relevant, interface scale bounds 100..200, persisted panel widths and removable generation-safe observer subscriptions. Font rendering preserves 64KiB input/16,384 glyph bound, font px 1..256, render height ≤1024, cache 64 entries/4MiB, label normal style with weights 400/600, UI label/tree bounds (128 nodes/depth 24, 63-byte previews, 1MiB total strings, draft 127 bytes/label 63 bytes). `TextDraw` only receives its established parameters; use no fabricated fonts or pixels. **Tests:** original native-ui-render and platform text UI tests mapped from `tests/ui/native_ui_render.m`, `tests/platform_media/platform_media_test.c` text cases; cache eviction/bytes, clipping/stride/capacity, all scale/preferences validation, observer removal/late callbacks, text fitting/layout and actual glyph raster evidence.

## 2. NATIVE-PRESENTER-SHADERS

**Effort:** Luna High. **Dependencies:** accepted window native shell view/lifecycle; `vexel-scene::ImageView` or exact `RgbaFrame` ownership contract after coordinator pins it; selected Metal/QuartzCore/CoreGraphics bindings. **Owned paths:** `native_present/{mod.rs,presenter.rs,shaders.rs,tests.rs}` plus owned `native_present/shaders/*.metal` resource files. Define per-window `Presenter` with checked borrowed-frame copy before returning, per-window reusable textures and pipeline, bounded in-flight GPU submissions, explicit pixel format/channel/alpha contract, recoverable no-drawable status, completion generation routing and teardown drain. Keep separate synchronous diagnostic readback/hash API only if legacy validation requires it; no global device resources coupled to a C window pointer. Preserve PNG/Metal interface 8192 axis and checked width×height×4/byte-count contracts; five-second diagnostic readback deadline where existing source specifies it. **Tests:** original tile/metal presentation tests and `platform_metal_present_and_verify`/`platform_metal_copy_and_hash` cases; exact bytes/readback hashes, device/layer unavailable, drawable missing, dimensions/overflow, failure/timeout, multiple windows isolation, asynchronous completion after reset/drop, resource lifetime and shader compile on supported macOS SDK.

## 3. NATIVE-MENUS-COMMANDS

**Effort:** Luna Medium. **Dependencies:** accepted window `WindowId`, owned command registry/state snapshot and command dispatch seam; current selected AppKit NSMenu/NSMenuItem; localization order/interface. **Owned paths:** `native_menus/{mod.rs,menus.rs,commands.rs,tests.rs}` only. Port the entire menu tree, separators, shortcut discovery, recent-item submenus (up to 12 recent SVG paths per macOS README), state enabling/checkmarks, full-screen toggles, option state, ruler context menus and command callbacks. Menus consume immutable owned state and emit exactly one typed command routed by live window generation. Preserve all `platform_viewer_action` IDs and modifier mapping; don't equate menu construction with app command implementation. **Tests:** `tests/app/platform_command_policy_test.c`, menu portion of `tests/ui/native_ui_render.m`, original menu test hooks / source assertions; cover all command IDs and check states, shortcut modifiers, stale generation, recent refresh, context position conversion, localization and callback faults.

## 4. NATIVE-DIALOGS-FILES-DROP

**Effort:** Luna High. **Dependencies:** accepted Rust document IO/save/job contracts and window generation/late callback API; selected NSOpenPanel/NSSavePanel/NSAlert/NSDragging/NSPasteboard; existing `vexel-platform-tasks`. **Owned paths:** `native_files/{mod.rs,open.rs,save.rs,drop.rs,clipboard.rs,dialogs.rs,tests.rs}` only. Implement open/save/export panels and unsaved/recovery/error dialogs including asynchronous completion cancellation; open URL/startup files, security-scoped lifetime, SVG-only drop rules, clipboard SVG/text/PNG and startup queue. Convert selected paths to owned validated UTF-8 strings; no borrowed C buffers. Preserve window path 4096 cap, dialog path 1024/text 4096, startup 8 entries, clipboard SVG 64KiB and existing extension/filter/overwrite rules; reject or explicitly report overflow. All completions carry window and operation generation; cancel/invalidate before owner teardown. **Tests:** `tests/app/project_save_test.c`, dialogs/platform window file tests, `tests/editor/editor_clipboard_ids_test.c`, clipboard tests, platform save/open test hooks and file fixtures. Cover cancel/accept/error, extension rules, invalid UTF8/long paths, drop enter/exit/perform filtering, startup saturation, scoped URL release, cancellation and stale completions.

## 5. NATIVE-ACCESSIBILITY

**Effort:** Luna High. **Dependencies:** accepted `vexel-ui` owned `SemanticsSnapshot`/tree contracts and live window generation; selected AX element/protocol/constants and NSView. **Owned paths:** `native_accessibility/{mod.rs,tree.rs,actions.rs,tests.rs}` only. Build a real native AX tree from snapshots, preserve IDs/roles/labels/value/actions/selection/visibility, convert pixel frames to screen coordinates with backing-scale and origin semantics, route actions through owned commands, post value/layout/focus notifications and safely unregister callbacks. No claim that the Rust snapshot itself supplies VoiceOver. Preserve 128 nodes and existing text/identifier caps; reject malformed snapshots without partially replacing prior accessible tree. **Tests:** `tests/editor/accessibility-localization_test.c`, `tests/editor/inspector_tab_reachability_test.c`, AX sections of `tests/ui/native_ui_render.m`; stable identity, tree replacement, hidden panels, frame conversion, action routing/staleness, notifications and teardown.

## 6. NATIVE-SETTINGS-RECENTS-WELCOME-LOCALIZATION

**Effort:** Luna Medium. **Dependencies:** settings UI model and accepted window/file/menus interfaces; selected NSUserDefaults, NSWorkspace, Foundation/AppKit; localization table/tooling contract. **Owned paths:** `native_preferences/{mod.rs,settings.rs,recents.rs,welcome.rs,localization.rs,feedback.rs,tests.rs}` only. Port preference read/write/default seeding, workspace/sidebar/density, recent path persistence/availability/open-failure, welcome surface actions, localized labels/numbers/plural messages and feedback/help. Use removable subscriptions and copied snapshots. Preserve 16-byte workspace field, 8 entries in `platform_window.h` event API; welcome/recents use `WELCOME_RECENT_PATH_CAP` (4096). Preserve menu recent-path count independently from source implementation; macOS README describes up to 12 SVG paths. Do not substitute 8 for 12 or infer a display-name cap not declared by the active structure, localization 128-byte keys/4096-byte text, welcome recent path cap from `welcome_model.h`; settings must retain test-domain isolation semantics. Welcome is custom Rust UI, not native system substitute. **Tests:** `tests/app/viewer_home_test.c`, `welcome_model_test.c`, `viewer_home_layout_fuzz.c`, settings tests, `tests/editor/accessibility-localization_test.c`, localization extraction/pseudo-locale checks and feedback diagnostics tests.

**Effort:** Luna High. **Dependencies:** accepted complete orders 0–6, window source gate, Rust document/model/render/timeline contracts. **Owned paths:** new `rust/app/vexel-app/**` app composition modules and executable source only; coordinator owns workspace membership, `vexel-platform-apple/src/lib.rs`, app crate manifest/resources/lock and all shared integration. Compose lifecycle, document open/save/cancel generations, media provider, custom UI `WidgetCanvas` with concrete `TextDraw`, menus, accessibility, Metal `Presenter`, preferences/welcome, recents, clipboard/drop and dialogs. Every adapter must be installed and failure observable; no fake defaults, legacy C backend, hidden fallback, or incomplete-path claim. **Tests/evidence:** migrate original `tests/app/*`, `tests/ui/*`, relevant `tests/editor/*`, `tests/platform_media/*` and `tests/mcp/*` app-bridge assignments without weakening fixtures/oracles; headless composition tests first, then broad macOS Apple Silicon GUI/E2E on minimum macOS 13 and current host covering launch, document lifecycle, text/image/GIF, IME, scale/display changes, menus/dialogs, VoiceOver, drop/clipboard, errors, cancellation, teardown and authentic character-animation demonstration. These are future gates, not planning results.

## Coordinator gates and shared proof

Before any module worker starts, coordinator accepts the safe DTO/work-budget contract, registers `native_media`, `native_text_ui`, `native_present`, `native_menus`, `native_files`, `native_accessibility`, and `native_preferences` in `vexel-platform-apple/src/lib.rs`, and lands compile-visible module roots. Separately coordinator adds the root app crate/workspace member and adapter modules only after its acyclic dependency review. This registration is not worker implementation and no unregistered body is claimed to compile. Workers may edit only their registered private module/test paths. Coordinator exclusively edits `lib.rs`, Cargo manifests/lock, workspace membership, shared interfaces, ledgers and freeze evidence. Each worker handoff is followed by registered-target compile/test and independent source/hash coverage review before integration.

## Shared proof and freeze gates

Each implementation order must name full original file/hash coverage, port every public function and private helper, derive all caps from source/tests, assign each original test/oracle once, add exact-edge and ownership/late-callback tests, and retain MPL-2.0/macOS-13/Apple-Silicon/custom-UI/owned-SVG restrictions. Evidence must identify exact Rust test names and fixture provenance; focused locked/offline target check and tests, API/feature review, per-callback ABI guard audit, main-thread proof, CF/ObjC ownership audit, allocation/cancellation/teardown review, output path/hash audit and independent review are required. macOS 13 runtime and broad GUI evidence remain separate release gates. No build/test was run for this proposal.
