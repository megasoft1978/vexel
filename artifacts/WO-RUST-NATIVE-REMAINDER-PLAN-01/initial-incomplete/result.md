# Native remainder readiness inventory

Read the active order, owner directives, original platform headers/implementations, Rust contracts, accepted native-window result, native binding audit, ADR0026/0027 and scoped original test sources. `native-inventory.json` records SHA-256 and token-discovered public/private function symbols for every file under `src/platform/**`; source path is the complete file-level test/limit mapping key. `ready-orders.md` assigns every native source family, private helper coverage, preserved bounds, adapter contract and original test family to disjoint future ownership scopes.

Current Rust provides accepted MainThread/native-call guards and native window source, but window source acceptance is not runtime acceptance. `vexel-scene::MediaProvider` requires real text and image outputs; `TextDraw` remains an injected callback and must be concretely installed. Proposed orders require owned CoreText outlines, ImageIO pixels/GIF output, CoreText UI glyph raster, per-window Metal presentation, full AppKit menus/dialogs/AX/file/drop/preferences/welcome and app composition. No fake font/pixel, default provider, C backend or incomplete application path is acceptable.

The existing Apple crate manifest already selects pinned objc2 0.6.5, objc2-* 0.3.2, block2 0.6.2 and audited helper/build units at disabled defaults. ADR0026/0027 and cached audit declarations supply evidence; this proposal adds no features or dependencies. Newer SDK 27 APIs still require explicit macOS 13 availability guards and runtime proof. ABI guards, main-thread confinement, CF/ObjC ownership, allocation/cancellation, generation-based late callback invalidation and ordered teardown are specified in the orders.

No production source, tests, manifests, lockfiles, artifacts outside this order, ledgers or STATE were edited. No tests, builds, network, install or GUI action was run. The user-named `artifacts/original603baseline` directory was not found; prior audit artifacts report baseline preservation and the accepted window order reports 603 legacy files/157 oracles, but the coordinator must locate the canonical baseline and perform its independently required source/index audit before accepting this plan. This is a readiness proposal only: no full native implementation, completed app, runtime, performance or release claim.
