# Decisions and unresolved proof gates

1. **Existing interface is sufficient for actual media adapters.** `vexel-scene::MediaProvider` requires both text layout and image decode and states providers return Rust-owned results with no default/fake. Use that directly. `ImagePixels` is premultiplied RGBA8, top-row first, with explicit byte count/stride/dimensions; its validation currently checks dimensions/stride/capacity but contains no image source or URI/GIF policy. Keep native image limits at adapter boundary. `TextRequest` validates 64KiB, 32 families × 256 bytes, size ≤4096, weight 100–900 and letter spacing ≤4096; `TextLayout` currently permits 65,536 glyphs and 262,144 commands. Native implementation must retain original stricter 16,384 glyph limit and actual CoreText outlines, returning `MediaError::Limit` beyond it. No fake fallback or legacy C dispatch.

2. **`TextDraw` needs an installed real adapter.** `vexel-ui::TextDraw<'a>` is an optional mutable callback stored by `WidgetCanvas`; absent callback can leave content undrawn. Application composition must construct a concrete CoreText renderer and pass it to every production canvas, propagate `false` as an observable rendering failure, and prove labels appear. Do not alter the shared UI crate in a native lane; if optionality needs changing, coordinator must issue a separately reviewed interface contract order.

3. **Selected binding closure exists; do not activate more features.** `vexel-platform-apple/Cargo.toml` presently selects AppKit NSVisualEffectView, NSImage, NSBezierPath, NSGraphicsContext, AppKit menus/panels/AX/text input, Foundation NSProcessInfo/NSUserDefaults/notifications/runloop/exceptions, CoreText CTFont/CTLine/CTRun, CoreGraphics contexts/path/images, ImageIO source/destination, Metal resources/commands/pipeline and QuartzCore CAMetalLayer. Exact pins and disabled defaults are in that manifest and `docs/dependencies/objc2-macos.lock.json`; ADR0026 locks the 16-package selected graph and ADR0027 adds NSVisualEffectView/cursor classes/NSProcessInfo. Audit artifact retains cached crate declarations and Apple SDK 27 extracts. New features are **not proposed** absent a specific declaration gap; do not use unselected CGImageSourceDestination or class APIs without proving current cached declaration and selected feature.

4. **SDK 27 does not establish macOS 13 runtime availability.** Use retained `artifacts/WO-RUST-NATIVE-BINDINGS-AUDIT-01/primary/availability-*.txt` and `sdk-*.txt` per symbol/class/function. Guard any API newer than 13 and keep older path valid. NSVisualEffectView is accepted only behind existing macOS 26 material gate (ADR0027); never replace with NSGlassEffectView. Binding compile/source evidence does not prove runtime/UI parity. Full macOS 13 GUI coverage remains future work.

5. **ABI and native ownership use accepted ADR0026 contract.** MainThread capability, private native handles, `!Send + !Sync` AppKit owner, catch-all `guard_native_call` at each public native operation and inbound Objective-C/C/block callback, owned bounded error latch, no Rust panic/Objective-C exception crossing those boundaries, no model borrow across reentrant native call. The accepted helper catches objc2 translated exceptions but raw C/CF calls, retain/release/destructors and abort cannot all be fenced; do not claim universal recovery. Invalidate generations, cancel work, unregister observers/delegates/AX targets, drain GPU work and release owners in ordered teardown. Late callbacks must be no-ops after generation invalidation.

6. **Original baseline locator is unresolved.** Requested `artifacts/original603baseline` is absent from scoped `rg --files`; `artifacts/WO-RUST-NATIVE-PLAN-01/source-audit.txt` says its read-only baseline retained every Rust/original603 file hash with HEAD/index. `artifacts/WO-RUST-NATIVE-WINDOW-01/coordinator-result.md` independently records preservation of 603 legacy files and 157 oracles, source-scope/HEAD/index audits. This proposal does not reproduce or claim a new independent 603-file/index preservation audit; coordinator must identify the canonical baseline artifact and do the work-order-mandated independent source603/157-oracle/HEAD/index audit before acceptance.

7. **Testing/runtime are distinct.** The accepted window result records focused source tests and locked offline check, but explicitly does not accept live GUI/macOS 13/timer/IME/display/cursor/runtime. Existing native code and older tests are assignment evidence only. Every full lane needs its own Rust parity tests and later real GUI acceptance; no test/build/runtime was run or inferred for this order.
