# Frozen revision 3 — readiness decisions

1. **Scope and preservation.** This is the same WO-RUST-NATIVE-REMAINDER-PLAN-01 revision 3 and eight whole implementation lanes. The historical R2 rejection in `r2-readiness-rejection/recheck.md` is unchanged. Existing R2 source/class/method/block entries are retained; R3 adds exact evidence rather than treating empty definition lists as absence of behavior. The 83-file native baseline, canonical 603 source list and canonical 157 original suite/fixture inputs all match their recorded hashes. `r3-preservation-audit.json` records exact input hashes and mismatches (none). No source, test, baseline, order, runner, manifest, lock, STATE or ledger was edited.

2. **Exact API evidence, never inferred features.** `native-inventory.json.r3_framework_api_proof` and `api-proof.md` enumerate 718 API identities and 2,138 original/planned use anchors. 504 records have a selected exact cached declaration plus public SDK availability evidence; 54 are source-owned callbacks/selectors rather than imported APIs; 160 remain explicitly blocked **coordinator metadata review gates**. Each blocked identity has a named R3-API-METADATA gate, exact source uses, cached declaration/signature/hash where present, effective feature delta, SDK signature/hash where present, a concrete nomination/review request, affected lanes, and a pre-worker stop condition. Multiple matching generated methods are candidates until the nominated typed adapter metadata is approved; they are not silently treated as proof. No future implementation worker is assigned declaration/availability discovery. These gates are proposed, not approved or adopted by this report.

3. **Availability proof.** Local SDK27 declarations carry exact introduced macOS annotations or are paired with the exact public SDK 11.1 declaration. A pre13 declaration proves availability by 11.1; it does not fabricate an earlier numeric introduction. Deprecation does not equal removal. MTLResidencySet/macOS 15, NSApplication activate/macOS 14 and other newer APIs cannot establish the macOS 13 path. Existing accepted NSVisualEffectView material behavior retains its macOS 26 gate and hidden older path. Runtime macOS 13 support remains unaccepted. API evidence is local-only; no SDK or upstream fetch was used.

4. **Known selection gaps are concrete.** CTFontTraits constants needed for original CSS traits are not selected merely because CTFont is selected; NSMenuItem state methods require NSCell; CGGeometry/CGAffineTransform helpers and Foundation NSPathUtilities/other utilities have exact feature gates in the catalog. Legacy AppKit controls/NSFont do not authorize native-widget adoption under the custom-UI lock. The safe custom model/TextDraw option is explicit at each relevant metadata gate. `NSSavePanel::setAllowedFileTypes` is a concrete selected, pinned, SDK-proven alternative (API-0718) to unselected UTType/setAllowedContentTypes, introduced 10.3/deprecated 12.0 and still declared. Its extension/filter/overwrite semantics require coordinator review against the exact original cases; UniformTypeIdentifiers is not added. No dispatch2/IOSurface lock record is treated as a selected package. CommonCrypto/dispatch calls have no selected matching binding and are explicitly blocked; concrete first-party completion/deadline/digest adapter signatures and owned module paths are proposed in ready-orders, with no raw extern or package adoption.

5. **Keep platform independent.** Apple currently has no scene/UI/base production dependencies. Proposed platform-owned DTOs, NativeControl/NativeStop and safe UI/window/completion contracts are fully spelled out in ready-orders. Root adapters implement the actual scene MediaProvider and UI TextDraw, translate full SemanticsSnapshot values, and preserve a first-stop latch where existing MediaError cannot express cancellation. No fake glyphs/pixels, callback defaults, borrowed-output lifetimes, model borrow across native calls, or scene/UI types inside Apple. Every original native limit and output validation applies. The exact 110/120 interface-text-scale mismatch with current WidgetCanvas is a coordinator-owned adapter/shared-contract gate, not permission to round or reject original values.

6. **Accepted window seams stay unchanged.** `r3_accepted_rust_seams` anchors353 existing declarations by exact file/line/signature/hash. NativeApp start/create/poll/destroy/shutdown and Window methods remain the actual interfaces; WindowId is slot+generation; NativeView is private. Presenter uses existing crate-private Window::surface_view. Root retains per-window/operation ownership and invalidates completion tokens before detaching and destroying. GPU callbacks retain owned completion state only. No new public native pointer, second fake view, raw C window or global device owner is introduced. Existing window/atomic/system source acceptance does not accept GUI, IME, display, cursor, timer, teardown or minimum-OS runtime.

7. **Sole original ownership is individual.** `r3_original_test_ownership`/`original-case-ownership.md` assign 748 function/helper/parameter cases and 6,920 individual conditions/assertion invocations/returns/commands/manifest fields across 120 named native/app/editor/UI/Metal/harness inputs. This includes original app/main Metal smoke/replay bodies, 20-frame/hash/order checks, platform_metal byte verification and all 14 native-shell screen/theme combinations. JSON manifests use exact token positions, including repeated values. Each case/check has one owner plus original path/function/line/expression/body hash and file hash. A harness owner is not a second case owner. Native media text tests remain solely lane 0; platform_text_ui tests lane 1; command policy lane 3; native shell integration renders lane 7. No nonexistent menu/AX subsection of native_ui_render is claimed.

8. **Limits are source facts.** 15,754 numeric/symbolic source/test anchors carry exact original path/containing function (or file scope), line, full text, record/file SHA256 and sole owner. This is a conservative superset including data/enum/oracle values, not a changed cap. PNG and Metal axis4096; PNG 16,000,000 pixels and 64MiB encoded; native image 32MiB input, 64Mi pixel count and 16084-axis; GIF 120 frames/4096-axis/32,000,000 total pixels/128MiB output; text 64KiB/16084 glyphs/262144 commands; cache 64/4MiB and font 256/render-height 1024 remain distinct. Welcome model and actual menu loop both use 8 recents; README 12 is a documentation discrepancy, never an inferred cap adoption. Root composition owns shared window interfaces; lane 6 solely owns settings/localization/recents/feedback headers and bodies, lane 1 owns text preference watchers/cache.

9. **Coordinator registration remains a hard prerequisite.** No worker edits lib.rs, Cargo manifests/lock, workspace membership, shared interfaces or ledgers. Coordinator alone reviews/registers native_adapter_contract and all seven native module roots, root app membership/adapters and every listed metadata gate before an affected worker starts. These are concrete compile-visible contract/metadata proposals with no adoption in this task. A future unregistered body is never build/test evidence. Every lane retains complete original functions/helpers and whole-file behavior; implementation/compile/target checks and independent review are later frozen orders. Broad GUI/E2E, fidelity/performance/release and authentic character-animation demonstration remain part of the unchanged full goal.

10. **No runtime or workflow claim.** Only bounded local source/cache/SDK reads and own artifact report writes were performed. No builds, tests, GUI, agents, review CLI, network, packages, staging/reset/deletion/commit or billing actions ran. The source/hash audit is not a test run. This report supplies full-scope source evidence and explicit blocked prerequisites; it does not approve those prerequisites, accept implementation, or declare release readiness.

The callable catalog is504 selected pairs,54 source-owned callbacks and160 explicit blocked gates.
