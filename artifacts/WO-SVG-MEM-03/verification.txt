## Memory accounting and limits

A local Apple Clang type-size probe reports the prior inline stroke layout as
176 bytes and the new layout as 56 bytes. The descriptor reduction is 120
bytes per shape, or 7,864,320 bytes (7.5 MiB) at 65,536 shapes, before stored
dash values. Dashed values are now stored only in a bounded document-owned
array. This is static type-size arithmetic; no RSS or corpus-level memory
measurement is claimed.

No broad UI/E2E suite, corpus run, fuzz campaign, or performance benchmark was
run for this work order.
