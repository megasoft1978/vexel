Implementation
- Added a responsive Drawing Asset selector and Add Cel action to the native
  timeline. The selector walks live project `image/svg+xml` assets and skips
  drawings whose raster dimensions or viewBox do not match the animation scene.
- Add Cel targets the selected drawing track at the integer playhead tick,
  replacing same-tick exposures using the session's undoable upsert operation.
  It refreshes timeline rows, invalidates frame/onion preview, sets the existing
  native-mutation notification, and reports the selected asset and tick.
- Added accessible action names and current-asset value. A bounded index cache
  is refreshed when the live bundle's asset count changes, including MCP asset
  insertions.
