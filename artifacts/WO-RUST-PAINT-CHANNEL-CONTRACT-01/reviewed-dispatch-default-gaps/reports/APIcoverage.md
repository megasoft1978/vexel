# Paint channel contract API coverage

| Requirement | Public surface or behavior | Evidence |
|---|---|---|
| Explicit required fill/stroke planner dispatch | `PaintChannelDefinitionPlanner::plan_owned_pattern_definition` and `plan_production_pattern(..., PaintChannel, ...)` | `paint_channel_contracts.rs`: planner selects the computed `FillOpacity` or `StrokeOpacity` value explicitly |
| Preserve old API and literals | Existing `DefinitionPlanner`, `plan_production_definition`, `PatternMapping`, tickets, and pattern publication signatures are unchanged | Frozen `contracts`, `decode_publication_contracts`, `render_integration_contracts`, and `paint_publication` suites pass |
| No implicit fill/default/equality fallback | The new route always requires a channel argument; mapping opacity is returned from that channel's computed style. Missing selected property resolves to the SVG initial `1` | New test proves fill `.25`, stroke `.75`, omitted fill `1`, and omitted stroke `1` |
| Centralized validation | Both production planner entry points call `validate_production_plan`; owner/source, canonical element, style spans, bounds/transform, result kind, mapping, post operations, expansion ranges/styles/transforms, work control and cancellation are validated once | Existing production filter/mask planner and bad mapping/kind tests pass; new route uses the same validator |
| Preserve pattern channel while suspended | Existing `PatternContinuation` stores complete `PatternMapping`, `PaintChannel`, draft/request/generation, and job identity; `request_mapped` and `complete_mapped` retain and consume it | Existing `computed_pattern_mapping_transfers_same_job_pixels_and_attaches_fill_and_stroke`; new fixture completes all four channel/value cases |
| Real builder/job publication | Fixture calls channel-aware production dispatch, then `request_mapped`, writes pixels to an actual `RasterJob`, calls `complete_mapped`, and checks the returned `PatternId`, paint opacity, channel paint table, and shape attachment | `paint_channel_contracts.rs` |
| Failure, rollback, cancellation and ticket guards | Shared validator returns the existing source span and typed errors; publication preserves atomic suffix rollback and mapped ticket identity checks | Existing tests cover bad mapping/kind, source/style errors, wrong target/owner, foreign/stale ticket/job, cancellation, lower error, rollback and wrong dimensions in `decode_publication_contracts.rs` and `render_integration_contracts.rs` |
| Downstream adapter adoption | Definitions adapters implement `PaintChannelDefinitionPlanner`; decoders may use `ChannelAwareProductionDecodeOperations` and `ChannelAwareProductionDecodeSession`, whose step requires that operation set | `README.md` documents the required route and semantics. The owned definitions adapter is a read-only reference and was not changed or used for build verification. |

No renderer backend, lower engine implementation, application runtime integration, or product acceptance is claimed.
