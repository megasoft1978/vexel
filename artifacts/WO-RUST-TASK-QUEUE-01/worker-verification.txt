Behavioral adaptations
  C borrowed void* contexts and cleanup callbacks become typed Send+'static owned context in
  TaskCallback and context Drop after the terminal slot transition, outside the mutex. A callback
  receives a lifetime-bound cancellation token, so safe code cannot retain a dangling C token.
  Rust callback panic is caught and published as failure with value 0. Reentrant worker shutdown
  requests stop and returns without self-joining; an external shutdown joins every worker.
  Thread-local worker identity prevents deadlock when cleanup requests shutdown while another
  thread is joining. Safe Rust ownership replaces the C active-call counter/death probe.
