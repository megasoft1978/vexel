## What this repository is

A macOS-first, C17 SVG editor: an owned XML/SVG parser, shape decoder and
software rasteriser, a custom-drawn editor with a docked timeline, SMIL/CSS
animation, and an MCP server so an agent can drive the same editor. The product
target is recorded in `docs/adr/0016-product-target-and-gates.md`; the interface
direction is `docs/adr/0017-ui-direction-blender-aligned.md`.

## How work is done here

Read `OWNER-DIRECTIVES.md`, then `AGENTS.md`. Every change travels as a frozen
work order in `work/`, is implemented, is checked by a **fresh read-only
verifier**, and is recorded in `ledger.jsonl` and `LEDGER.md` with the SPEC
SHA-256. Three lessons that cost real time in this repository:

1. **Never freeze an acceptance criterion the candidate cannot literally
   satisfy.** "Record the pre-change failure" for a test that cannot compile
   before the change, or "save byte-identically" when the check only
   materialises in memory, will fail verification. State the achievable form.
2. **Run a symbol-resolving probe before raising a limit.** Two rounds were spent
   guessing which budget refused real drawings; printing
   `dladdr(__builtin_return_address(0))` at the failure path named `add_edge`
   immediately.
3. **When a deliberate behaviour changes, the test that encoded the old
   behaviour is the thing to fix — never the guard.** The editor's root-transform
   guard, the raised budgets and the new workspace/tool-options layout each
   required updating tests that had pinned the old behaviour.
