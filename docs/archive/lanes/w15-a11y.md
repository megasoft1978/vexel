# W15 accessibility and localization readiness

Implements r5 WO-6 and WO-9 for the macOS editor. All C sources remain below
800 lines; the new platform adapter, keyboard handling, and status/localization
helpers are in separate files. The lane adds no dependencies and does not
change serialized SVG bytes.

## Changes

- Added the macOS VoiceOver tree bridge for editor controls, layers, inspector
  fields, active tool state, and canvas selection. Layer rows expose full
  labels, disclosure and selection state, plus separate checkbox elements for
  visibility and locking. Their help text and state values describe the action
  and current state. Status and selection announcements are change-gated.
- Added Tab/Shift-Tab focus movement and focus-aware arrow, Return, and Space
  handling. Text fields keep normal editing keys and commit before Tab moves to
  the next control.
- Added persisted interface text sizes from 100% through 200%, laid out with
  the interface metrics and CoreText font size. The preference does not change
  canvas zoom. Existing system appearance, increased-contrast, and reduced-
  motion preference observation remains active.
- Added a bounded localization API, 319 registered fallbacks, and the English
  `Localizable.strings` table. Editor labels, status text, native menus,
  accessibility help, and fixed dialog copy use stable keys. Counts and SVG
  measurements use locale-aware formatters in the live app; SVG values are
  formatted only for display. The table also has welcome and settings keys for
  those app surfaces.
- Added an RTL-marked, 2× pseudo-locale test hook, resource extraction checks,
  source-byte preservation coverage, and light/dark headless goldens at 200%.
  Build output and packaged app resources both include the string table.
