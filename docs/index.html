Vexel

A native SVG workbench for Apple Silicon Macs. Inspect and edit vector documents, explore SMIL animation, and work through local MCP tools.

Written in C17, with a custom-drawn interface and an owned SVG parser and rasterizer. An evolving application for a supported SVG subset.

Edit and animate

Layers and attributes, shape and text tools, supported path node editing, multiple selection, transforms, snapping, rulers/guides, clipboard, undo history, command palette and PNG export.

The docked timeline offers play/pause, seeking, preview modes and speed, track scrolling, keyframes and spline easing editing for supported tracks.

Local MCP workflow

The app hosts a same-user local socket. The stdio relay provides document and animation tools, sampled PNG rendering and live UI controls. GUI and MCP share selection, source edits and undo history.

Headless document records support document tools; live UI controls are unavailable for them. Filesystem access requires explicitly granted directories.

Demo: Un cuore per due

A vector trace/reconstruction with transform articulation and squash/stretch. Twelve named spline-eased tracks form an 11.01-second SVG scene.

This demo does not establish exact original-drawing fidelity, bone skinning or path morphing. The GIF is an external workflow output: MCP frame rendering succeeded, but built-in full-page animation export failed.

Build and run

Apple Silicon, macOS 13+, Xcode Command Line Tools, CMake 3.25+ and Ninja. No configure-time downloads or third-party library dependencies.

git clone https://github.com/megasoft1978/vexel.git
cd vexel
./dev build
./dev run docs/examples/un-cuore-per-due-vector-rig-v2.svg
./dev t --all

For Release: cmake --preset mac-release, then cmake --build --preset mac-release. The executable is build/mac-release/bin/svgworkbench. Launch without a file for Welcome/Open; ./dev bundle creates the application bundle.

./build/mac-debug/bin/svgworkbench --render-frame file.svg --size 1280x800 --time 1.5 --out frame.ppm
./build/mac-debug/bin/svgworkbench --render-animation file.svg --fps 8 --duration 10 --out frames/

Frame sequence output uses an existing directory and bounded PPM frames with transparency flattened over white.

MCP setup and animation support

Run build/mac-debug/bin/vexel-mcp as the stdio relay while the app is running. Set the same VEXEL_MCP_SOCKET path in both processes. Grant directories with VEXEL_MCP_ALLOWED_DIRS or the private ~/.config/vexel/mcp-allowed-dirs.txt file. Live documents use active and window:N identities; VEXEL_MCP_DISABLE_LIVE=1 disables live control.

Refresh element handles after each mutation. Coordinated timing attributes need atomic transaction updates. Export has frame, size and pixel budgets; successful sampled frames do not establish successful full-page animation export.

Playback supports numeric geometry/opacity, solid colors, transform types, simple timing/repetition, linear/discrete/spline/paced interpolation and bounded line-based motion paths. Track editing supports a narrower subset. See animation contracts and MCP contracts and limits.

Limits and rights

SVG support is incomplete. SVGZ, external resources, scripts, CSS/event animation timing, curved motion paths and active path morphing are unsupported. Some filter/mask, group opacity, pattern and clip cases remain limited. Renderer acceptance work is deferred; no exact fidelity or performance claim is made.
