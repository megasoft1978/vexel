One prompt becomes tool calls on your open document.

The app runs as the MCP server itself, over stdio. Each call is applied to the document you are looking at.

A small editor with the parts animation needs.

Canvas

Draw shapes and paths, select with eight resize handles, set fill, stroke and stroke-width presets in the inspector.

Timeline and easing

Property tracks, keys, loop playback and a bezier easing editor. Timeline edits share the project undo history.

Owned SVG renderer

Our own SVG decoder and renderer in Rust, no webview. Q, T and S path commands and gradients work. Arc commands do not yet.

MCP batch and undo

batch applies ordered scene and timeline operations as one undo step, rolling back on the first failure by default.

Exports

GIF, APNG, PNG frame sequence, MP4 and MOV in H.264 or HEVC, plus HEVC with alpha.

Build it, then register it with your agent.

There is no download yet. Requires an Apple Silicon Mac, macOS 13+ and rustup; the pinned toolchain installs itself.

cargo build --release -p vexel-app
./build/rust/aarch64-apple-darwin/release/vexel

Serve MCP on stdio from the same binary with --mcp-preview; --grant-dir (repeatable) limits which folders it may read and write.

./build/rust/aarch64-apple-darwin/release/vexel --mcp-preview --grant-dir /Users/me/Artwork

Add to ~/.codex/config.toml. Use absolute paths.

[mcp_servers.vexel]
command = "/absolute/path/to/vexel/build/rust/aarch64-apple-darwin/release/vexel"
args = ["--mcp-preview", "--grant-dir", "/Users/me/Artwork"]
startup_timeout_sec = 10
tool_timeout_sec = 60

Register at user scope:

claude mcp add vexel --scope user -- \
  /absolute/path/to/vexel/build/rust/aarch64-apple-darwin/release/vexel \
  --mcp-preview --grant-dir /Users/me/Artwork

Or a project .mcp.json:

{
  "mcpServers": {
    "vexel": {
      "type": "stdio",
      "command": "/absolute/path/to/vexel/build/rust/aarch64-apple-darwin/release/vexel",
      "args": ["--mcp-preview", "--grant-dir", "/Users/me/Artwork"]
    }
  }
}

Alpha, and honest about it.

Pre-release software. Things work, and some things are missing.

Working

  • Live-preview MCP, 53 tools including batch
  • Native timeline, loop playback, bezier easing editor
  • GIF, APNG, PNG frames, MP4/MOV, HEVC alpha export
  • Q/T/S path commands in SVG import
  • Linear and radial gradients, inspector fill control
  • Add key at the playhead, per-key easing

Partial

  • SVG import: 21 of 39 corpus files open; the count predates recent fixes
  • Native timeline MCP: six property-track tools routed; some stay unrouted
  • Export: GIF is synchronous and long loops are stride-sampled

Not yet

  • SVG arc commands
  • Signed, notarized builds
  • A downloadable release
  • Export progress and cancellation over MCP

Limitations. No Developer ID signing or notarization, so build from source. The real-window UI end-to-end script is written but has not been run live, and GUI end-to-end tests do not run on hosted CI. Details in STATUS.md.
