MCP

Vexel runs a local MCP server (vexel-mcp) over stdio. An agent edits the same open document as the app. Replace the path with your built binary and grant only the directories you intend to open.

Claude Code .mcp.json entry:

{
  "mcpServers": {
    "vexel": {
      "type": "stdio",
      "command": "/absolute/path/to/vexel/build/mac-release/bin/vexel-mcp",
      "args": [],
      "env": { "VEXEL_MCP_ALLOWED_DIRS": "/Users/me/Artwork" }
    }
  }
}

Full setup, Codex and Claude Desktop configs, tool list and limits: docs/mcp.md
