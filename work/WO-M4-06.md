# Required implementation
1. Build a bounded local-ID index for SVG elements. Treat `<defs>` as non-rendering and `<symbol>` as non-rendering unless instantiated by `<use>`. Support `href="#id"` and namespaced `xlink:href="#id"` only; external URLs, data URLs, missing references, duplicate IDs, cycles, and unsupported targets must fail predictably without fetching anything.
2. Expand `<use>` over supported shapes and groups. Support finite x/y translation and `<symbol>` width/height plus a finite viewBox mapping. Inherit paint from the `<use>` host according to the documented subset. Cap use/reference depth at 16 and expanded renderable instances at 65,536 per document. Avoid copying or rewriting source bytes.
3. Support `linearGradient` and `radialGradient` with at least two and at most 256 stops, literal supported stop colors, bounded finite offsets, `stop-opacity`, `gradientUnits` (`objectBoundingBox` and `userSpaceOnUse`), and `spreadMethod="pad"`. Support gradient transforms only where implemented and tested; reject unsupported spread modes, units, href inheritance, and stop syntax explicitly. `fill="url(#id)"` and the CSS `fill` equivalent may resolve only local gradients. Keep radial behavior and defaults tied to the cited SVG spec.
4. Support `clip-path="url(#id)"` and the CSS `clip-path` equivalent for local `<clipPath>` definitions built from supported basic shapes and paths. Support `clipPathUnits` objectBoundingBox and userSpaceOnUse. Combine child clip geometry by union; intersect the result with the painted shape in the scalar rasterizer. Enforce a bounded number of clip children and a checked clip-test work budget. Unsupported nested clip paths, external URLs, filters, masks, and unsupported clip contents return stable diagnostics.
5. Split the shape traversal/definition handling into cohesive modules so touched source files remain below 800 lines. Add a short module README for each new module and document ownership, limits, supported semantics, and diagnostic behavior.
6. Add unit/integration tests for local use/group/symbol references, x/y and viewBox transforms, reference inheritance, missing/external/cyclic references, expansion/depth limits, linear/radial gradient endpoints and stop interpolation, stop alpha, both gradient units, clipping union/intersection, both clip units, CSS and presentation clip-path, unsupported values, and deterministic output. Add small independent `rsvg-convert` differential fixtures for each supported behavior; keep existing shared-pixel thresholds unchanged.
7. Run the 58-file corpus harness after the changes. Preserve every input hash and supplied Inkscape baseline. Report outcomes and supported preview count by tier; count only successful renders. This remains open/index plus selected-fixture evidence, not full-render parity.
8. Add fixed reference/paint-server raster workloads with raw trials, median/p95, throughput, output hashes, and process RSS. Compare existing workloads to the frozen base and record any regression; do not make public speed claims.
