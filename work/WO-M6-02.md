# WO-M6-02 — Focus, commands, and semantics

## Goal
Extend the retained UI tree with owned accessible labels/values, stable semantic snapshots, cyclic keyboard focus, and a bounded command registry.

## Allowed paths
`work/WO-M6-02.md`, `src/ui/**`, `app/ui_*`, `tests/ui/**`, `tests/test_ui_chrome_golden.py`, `CMakeLists.txt`, `bench/results/WO-M6-02.json`, `docs/PERF.md`, `STATE-laneB.md`, `LEDGER-laneB.md`, `docs/ui/**`.

## Acceptance
- Labels and values are copied into bounded tree storage and reject lengths above the declared limit.
- Semantic snapshots preserve stable IDs, parent IDs, role, label/value, and disabled/checked/focused state in tree order.
- Tab and Shift-Tab cycle through enabled controls; Enter/Space activates the focused control and reports its command ID.
- Registered key bindings dispatch deterministically and reject duplicate IDs/bindings and capacity overflow.
- Demo controls expose names, shortcut bindings, and keyboard semantics; tests verify repeatable snapshots and keyboard reachability.
- Release focus benchmark records 128-node traversal latency, RSS, and binary bytes.
- `./dev verify`, Debug/Release build, and ASan/UBSan CTest pass.
