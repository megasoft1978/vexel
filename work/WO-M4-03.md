# Goal
Render bounded SVG fills with spec-correct nonzero/evenodd coverage and deterministic antialiasing, validated against librsvg and measured on fixtures and the existing read-only corpus.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/research-r4/05-revised-roadmap.md`, `src/raster/README.md`, `src/raster/shape_render.c`, `src/raster/shape_render.h`, `src/svg/shape/README.md`, `tests/svg/shape/test_shape.c`, `tests/test_shape_render.py`, and `reports/M4/head-to-head.json`.
- Normative semantics: W3C SVG 2 painting and fill rule specifications, https://www.w3.org/TR/SVG2/painting.html (consulted 2026-10-09); this is a specification reference, not source code.
- Independent renderer: locally installed `rsvg-convert`; retain its exact version and fixture output hashes.
- Prior shape/path evidence under `artifacts/WO-M4-01/` and `artifacts/WO-M4-02/` is immutable and must not be overwritten.

# Existing contracts and invariants
- C17, macOS Apple Silicon 13+ only; no portability work, dependency, system package installation, or network access.
- `svg_shape_document` owns bounded flattened edges and fill metadata; raster output is caller-owned RGBA and source bytes remain borrowed/unchanged.
- ViewBox uses centered meet mapping. Fills paint in element order; nonzero and evenodd rules are evaluated per element. `fill="none"` does not erase prior output.
- Preserve stable failures, checked dimensions/allocation arithmetic, transparent black outside fills, and deterministic output across repeated runs on this host.
- Keep raster work explicitly bounded. Antialias sample evaluations count toward the work cap; the renderer must reject excessive work before entering the pixel loop rather than silently reducing quality.
- No CSS, stroke, gradients, clip, use, text, images, or full SVG fidelity claim is added here.
