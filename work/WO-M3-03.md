# Goal
Schedule immutable source snapshots on the bounded macOS worker queue with deterministic cancellation, cleanup, and generation-safe result delivery.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/research-r4/05-revised-roadmap.md`, `docs/research-r4/02-work-order-template.md`, `docs/adr/0006-m1-04-owner-quiescence.md`, `src/platform/platform_task.h`, `src/platform/macos/README.md`, `src/platform/macos/platform_task.c`, `src/svg/index/README.md`, `src/svg/index/index.h`, and `src/spatial/README.md`.
- Build on the existing opaque `platform_task_queue`; preserve its capacity 1–64, worker count 1–4, owner-quiescence destroy contract, and generation filtering.
- The queue currently borrows callback context and offers no terminal cleanup for queued cancellation. Add an owned-submit API without changing existing borrowed-submit behavior.
- macOS-only target: Apple Silicon, macOS 13+, Xcode Apple Clang. No network, new dependencies, external algorithms, or GPL SVG-editor source.

# Existing contracts and invariants
- C17, Apple Silicon macOS 13+ only, checked arithmetic, pointer+length inputs, no VLAs or unsafe string functions.
- Snapshots own an immutable copy of their source bytes and use atomic retain/release. A caller must own a snapshot reference while passing it to the scheduler.
- A scheduler is controlled by one owner thread. Worker callbacks read immutable snapshots only; shared scheduler accounting is synchronized.
- Queue callbacks cooperatively check cancellation. A stale generation never becomes pollable. Every accepted owned task invokes its context cleanup exactly once after callback return or queued discard.
- Destroy requires owner quiescence, then shutdown/join completes before any queue or scheduler storage is released.
- A scheduler bounds queue capacity and aggregate in-flight snapshot-reference bytes. Failed submission retains caller ownership and does not reserve bytes.

# Required implementation
1. Add `platform_task_submit_owned` with a context cleanup callback. Preserve `platform_task_submit` as the existing borrowed-context API. On every successful owned submission, invoke cleanup exactly once after callback return or after a queued task is discarded by cancel, generation advance, or shutdown. Never call user cleanup while holding the queue mutex. On failed submission, do not invoke cleanup or take context ownership.
2. Add an immutable, refcounted source snapshot API. Copy a pointer+length byte slice up to 256 MiB, expose only const bytes, retain/release safely across threads, reject invalid pointers/overflow/over-limit input before publishing a snapshot, and allow the empty slice.
3. Add an opaque owner-thread scheduler that uses the existing platform queue. Bound active task capacity to 64 and aggregate in-flight snapshot-reference bytes to a configured nonzero cap no greater than 256 MiB. A successful submit retains the snapshot and transfers only the internal task context; on failure the caller retains the snapshot and accounting remains unchanged.
4. Worker jobs perform a deterministic bounded snapshot scan, checking cancellation at least every 64 KiB, and return task ID, generation, success, and a stable 32-bit digest. Polling exposes only current-generation results. Cancellation and generation advance suppress stale results.
5. Add deterministic one-worker tests, randomized seeded multi-worker schedule/cancel/generation tests, duplicate/full/backpressure tests, snapshot ownership and source-mutation tests, cleanup exactly-once tests for success/queued cancel/stale generation/shutdown, and 1,000 open/cancel/join cycles. Keep module sources under 500 lines where practical and below 800 lines hard.
6. Add a macOS ThreadSanitizer preset and `./dev tsan` target limited to the worker/snapshot test when supported by the installed Xcode toolchain. Report an explicit skip only if the compiler/runtime proves unsupported; do not mask race reports.
7. Add module READMEs documenting thread ownership, snapshot lifetime, queue cleanup timing, memory bounds, errors, and tests. Record a deterministic 1,000-cycle scheduler benchmark and machine/compiler/build metadata in JSON.
