# Goal
Render bounded SVG strokes on basic shapes with deterministic cap, join, and dash behavior, validated against librsvg and measured on fixtures and the read-only corpus.

# Existing contracts and invariants
- C17, Apple Silicon macOS 13+ only; no portability code, dependency, network access, or platform changes.
- Source bytes are borrowed, preserved exactly, and never mutated. Diagnostics preserve source byte offsets.
- Existing fill rules, shape painter order, source retention, and 4x4 deterministic coverage remain unchanged for unstroked content.
- Stroke paints after fill for each element. Stroke color defaults to none; explicit `stroke="none"` emits no stroke. Width is in user units and transforms with geometry using the existing affine transform.
- First supported stroke subset: direct presentation attributes on `line`, `polyline`, `polygon`, `rect`, `circle`, and `ellipse`. A stroked `path` is rejected as unsupported until subpath boundaries are represented explicitly. CSS inheritance, `style`, percentages, vector-effect, markers, and filters remain unsupported.
- All dash lists, edge counts, work estimates, and numeric values are bounded and overflow-checked. Unsupported or excessive input fails with a stable category and source offset; never silently approximates by dropping segments.

# Required implementation
1. Parse direct stroke presentation attributes for the supported basic shapes: `stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`, `stroke-miterlimit`, `stroke-dasharray`, and `stroke-dashoffset`. Support existing literal color syntax only; defaults follow SVG for width/cap/join/miter and dashing. Reject malformed, non-finite, negative, excessive, odd-separator, or overlong dash input with stable diagnostics.
2. Rasterize each basic shape's stroke after its fill, retaining element order and the existing 4x4 sample grid. Support butt/square/round caps, miter/bevel/round joins with miter-limit fallback, and positive dash arrays including odd-length pattern duplication, phase offset, and continuity along the ordered outline. Handle zero-length edges and fully degenerate paths deterministically. Do not change unstroked output hashes.
3. Bound dash elements (maximum 16 values), stroke width and miter expansion, edge/sample work, allocation arithmetic, and temporary state. Excessive work is rejected before raster loops. Stroked `path` input fails explicitly as unsupported rather than being drawn with incorrect joins.
4. Add unit and `rsvg-convert` differential fixtures for every cap/join mode, miter fallback, solid/dashed/offset/odd dash arrays, fill-before-stroke painter order, transforms, and degenerate/limit cases. Compare raw straight RGB on jointly covered pixels with max delta <=1; interior differences are zero; within one pixel of coverage boundaries alpha delta <=160; at most 120 differing edge pixels per fixture. Validate deterministic repeated bytes and exact diagnostic offsets. Reports include tool/compiler/host, hashes, and unavailable metrics.
5. Extend the shape fuzz generator to vary stroke attributes and degenerate line/rectangle/polygon geometry; run at least 1,000,000 ASan+UBSan cases with zero reports, crashes, hangs, or invariants. Add fixed line/curve/dashed workloads to the raster benchmark and report median/p95, throughput, output hash, and RSS against the frozen base.
6. Rerun `./dev bench-corpus --run` and `--check`; keep all 58 outcomes, hashes, `reports/M4/head-to-head.*`, and the generated section in `docs/PERF.md` synchronized. Report actual newly previewable files, per-tier time/RSS where available, the 100 MiB wedge, and that this is open/index rather than full-render parity.
