# Goal
Add a bounded, allocation-free XML tokenizer that retains the caller's original bytes and reports checked byte spans for XML syntax used by SVG.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/adr/0002-source-preservation-and-provenance.md`, `src/base/base.h`, `src/base/README.md`, `src/base/base.c`, `docs/research-r4/05-revised-roadmap.md`.
- XML syntax reference: W3C XML 1.0 Fifth Edition, https://www.w3.org/TR/2008/REC-xml-20081126/ (Recommendation dated 2008-11-26; stable reference).
- Reference parser for valid-corpus comparison: Python 3.12.8 standard-library Expat 2.6.4 available in the project host. Record actual versions and fixture hashes in evidence; do not add a runtime dependency.
- Frozen tests/oracles: existing `tests/oracle/**`, `tests/golden/**`, and corpus manifest/fixtures are read-only. New tests must be outside frozen directories.
- No external source code, network fetch, external entity resolution, or SVG editor implementation source.

# Existing contracts and invariants
- C17; Apple Silicon macOS 13+ only. No other OS implementations or stubs.
- `base_bytes` is borrowed input. Token spans are half-open byte offsets into that unchanged input and never own or normalize source bytes.
- Tokenizer must not allocate, perform I/O, resolve entities, load resources, or mutate input. Caller supplies the fixed token buffer and explicit limits.
- All malformed input, unsupported DTD syntax, output exhaustion, and configured-limit hits return a category and an in-range byte offset; no partial token sequence is reported as success.
- XML byte offsets count the original UTF-8 byte stream. Accept UTF-8 only; reject malformed UTF-8, NUL, invalid XML characters, and unsupported encodings with diagnostics.

# Required implementation
1. Add a public XML tokenizer API under `src/svg/xml/` with token kind, half-open source span, diagnostic category/offset, caller token storage, and explicit options/limits. Document ownership, offsets, complexity, unsupported constructs, and exact limits in a module README.
2. Recognize XML declaration/processing instructions, comments, start/end/empty-element tags, qualified names, quoted attributes, character data, and CDATA. Attribute names and values, element names, prefix/local-name subspans, comments, PI data, text, and CDATA content must refer to exact source bytes. Preserve all whitespace and quote style through source retention; do not decode or normalize entities.
3. Track matching element names and depth without recursion. Detect duplicate attributes, malformed quotes/tags/comments/PI/CDATA, invalid name/UTF-8/XML characters, multiple roots, and incomplete documents with stable error categories and byte offsets. Treat namespace declarations as ordinary attribute tokens while exposing QName prefix/local spans; do not perform namespace URI resolution.
4. Reject every document type declaration and entity declaration at its opening byte. Predefined/numeric entity references remain lexical bytes inside text/attribute spans. No entity expansion or network/file access is permitted.
5. Enforce the defaults and allow caller-lowered caps: input bytes 16 MiB, nesting depth 256, total nodes 1,000,000, attributes per element 4,096, total attributes 1,000,000, and one text/CDATA run 4 MiB. Arithmetic must be checked before every span/count update. Output exhaustion is a normal diagnostic.
6. Add focused C tests for all token kinds/spans, namespace QName spans, mixed line endings, comments/PI/quoted attributes/text/CDATA, empty and nested elements, error categories/offset boundaries, each limit, output exhaustion, and unchanged input bytes. Add deterministic malformed-input generation and assert every error offset is <= input length.
7. Compare all valid pinned corpus fixtures that are well-formed XML against Python's Expat reference parser. Record Python/Expat versions, fixture IDs/hashes, parse outcomes, and any intentionally unsupported DTD cases; reference parser is test-only.
8. Add a deterministic 60-second ASan fuzz command that feeds generated bounded byte strings through the tokenizer, checks token spans and diagnostic offsets, and records seed, iterations, elapsed time, and sanitizer status. Fuzzing must write only to `.cache/` and artifacts for this WO.
9. Keep all new source/test files below 500 lines where practical and below the 800-line hard limit. No serializer, tree builder, SVG semantics, DTD support, third-party code, or performance claim.
