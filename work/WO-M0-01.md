# Existing contracts and invariants
- Apple Silicon macOS 13+ only; Python standard library only; no system package installs.
- Only public fixture/test data may be fetched. Fetch only HTTPS raw file URLs from `raw.githubusercontent.com/web-platform-tests/wpt/da1355b3fc629f97f8194884ab113da1ba3c7990/svg/` and its pinned root `LICENSE.md`; no git clone, archive download, API requests in the fetcher, or arbitrary host URLs.
- WPT fixtures retain their 3-Clause BSD provenance and copyright notice; do not relicense them as MPL. Original Vexel-authored fixtures are MPL-2.0. Do not claim W3C conformance or publish performance claims from this development subset.
- Exclude old `svg/import/`, files with unclear or conflicting per-file rights, proprietary/user files, external linked resources, executable scripts, and all GPL SVG-editor source.
- Never fetch resources from the application while opening SVG documents. Corpus fetching is a separate explicit developer command.
- Every accepted manifest record has a stable fixture ID, local path, content SHA-256, source URL/origin, license identifier and license URL, feature tags, UTC retrieval/creation time, and any modification note.

# Required implementation
1. Add a deterministic JSON corpus manifest with at least 20 SVG fixtures spanning basic shapes, paths, metadata/namespaces, style, text, embedded image, and stress-oriented features. The fixture selection must be diverse; local synthetic fixtures are not described as representative user documents.
2. Use only source data with an unambiguous recorded license. The pinned WPT BSD license permits software-development fixture use; copy its license notice into the corpus license directory and record the pinned source revision. Any original fixture must be clearly labeled `project-authored` and MPL-2.0. Exclude uncertain items and list exclusions/reasons in `docs/corpus/PROVENANCE.md`.
3. Add `scripts/fetch_corpus.py` with `--fetch`, `--verify-only`, and deterministic `--list --feature TAG` modes. It reads only the checked-in manifest, validates all fields/paths before I/O, uses an HTTPS host/repository/revision allowlist, rejects redirects off the pinned host/path, applies a per-file size cap of 2 MiB and bounded timeouts, streams SHA-256 verification, and atomically installs only byte-exact files. Existing valid fixtures require no network; a digest mismatch must fail without replacing the existing destination with unverified bytes.
4. Emit deterministic machine-readable check output, sorted by fixture ID. `--verify-only` performs no network requests and checks manifest digest, file hashes, license metadata, feature coverage, safe relative paths, and exact fixture count. `--list --feature TAG` returns stable sorted IDs.
5. Add standard-library tests for manifest/schema and feature coverage, deterministic filtering, traversal and URL rejection, redirect rejection, hash mismatch, partial-download cleanup, and successful mocked pinned-host fetch. Tests must not need external network.
6. Keep user/private data out of the corpus; do not add unrelated standards or renderer code. Record source URL, exact WPT revision, source-file hash, license URL/hash, retrieval timestamp, and modification status in retained documentation.

# Acceptance criteria (machine-checkable)
- AC-1 `python3 scripts/fetch_corpus.py --fetch` exits 0 on a clean checkout, validates every pinned digest, and reports at least 20 fixtures; evidence `artifacts/WO-M0-01/fetch.txt`.
- AC-2 `python3 scripts/fetch_corpus.py --verify-only` exits 0 with no network access and confirms manifest SHA-256 and file hashes; evidence `artifacts/WO-M0-01/verify-corpus.txt`.
- AC-3 `python3 scripts/fetch_corpus.py --list --feature path` emits deterministic, lexically sorted fixture IDs and returns at least one record; repeated output is byte-identical; evidence `artifacts/WO-M0-01/query.txt`.
- AC-4 `python3 -m unittest tests.test_corpus_fetch` exits 0 and covers all negative/positive fetch cases; evidence `artifacts/WO-M0-01/tests.txt`.
- AC-5 manifest records contain required provenance fields for every fixture, all expected feature families are present, no ambiguous-license entries are included, and the pinned WPT license notice/hash match the declared source; evidence `artifacts/WO-M0-01/provenance-check.txt`.
- AC-6 `python3 scripts/ledger.py validate ledger.jsonl`, `python3 scripts/wo_validate.py WO-M0-01 --ready`, and `git diff --check` exit 0; evidence `artifacts/WO-M0-01/local-checks.txt`.
