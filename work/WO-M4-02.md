# Existing contracts and invariants
- C17, macOS Apple Silicon 13+ only; no portability code, dependency, network access, or platform changes.
- Source bytes are borrowed, preserved exactly, and never mutated. Diagnostics retain byte offsets into original XML source.
- Existing `M/m L/l H/h V/v C/c Q/q A/a Z/z` path commands and their relative/repeated-group semantics remain unchanged.
- `S/s` reflects the previous second cubic control point only after `C/c/S/s`; otherwise its first control is the current point. `T/t` reflects the previous quadratic control point only after `Q/q/T/t`; otherwise its control is the current point. Any intervening nonmatching command resets reflection context. Relative control/end coordinates are relative to the segment start.
- Coordinates, commands, flattened edges, recursion, and raster work retain explicit existing caps. Exhaustion returns a stable nonzero diagnostic and source offset; it never silently truncates geometry.
- Paths keep their fill closure and per-element fill-rule behavior. This order adds no stroke, CSS, gradients, clipping, references, filters, text, images, or full SVG claims.
