# Goal
Expand the bounded SVG geometry core with common basic shapes and checked affine/group transforms, selected from the real-corpus feature inventory. Preserve deterministic rendering and source bytes.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/research-r4/05-revised-roadmap.md`, `docs/adr/0001-product-and-platform-locks.md`, `docs/adr/0012-proceed-to-m4.md`, `reports/M4/corpus-feature-frequency.md`, `reports/M4/corpus-feature-frequency.json`, `src/geom/README.md`, `src/geom/geometry.h`, `src/svg/shape/README.md`, `src/svg/shape/shape.h`, `src/raster/README.md`, and `src/raster/shape_render.h`.
- SVG geometry and transform semantics are normative references only: W3C SVG 2 Shapes and Coordinate Systems / Transformations specifications. Record URLs and consultation date in the module README; do not copy source code.
- M4 priority is based on the 58-file external corpus. Input files and baseline remain read-only; store only paths, hashes and measured aggregate evidence in the repository.
- macOS Apple Silicon only; C17; no new dependency or external resource loading. `rsvg-convert` is the installed independent PNG reference if present.

# Existing contracts and invariants
- Input bytes remain borrowed and unchanged; decoded arrays have explicit ownership and documented bounds.
- Existing root viewport, rect and path behavior remains deterministic and regression-tested.
- All numbers and matrix results must be finite and bounded before allocation or raster work. Transform composition order must match SVG semantics and be covered by tests.
- Fill geometry is supported in this work order; open line shapes have geometry but do not claim visible output until stroke support is implemented in M4-04.
- Group nesting, transform count, points, flattened edges, pixel count and render work are explicitly capped. Unknown metadata and editor attributes are safely ignored or diagnosed without discarding source.
- No CSS cascade, stroke, gradient, clipping, use/symbol expansion, text shaping or image decoding is added here.

# Required implementation
1. Add a documented 2D affine matrix API with finite-input/output checks, composition, point mapping and bounds mapping. Confirm multiplication/composition order against independent double-precision calculations.
2. Decode and render filled `circle`, `ellipse`, `polygon`, and closed `polyline` geometry; decode `line` geometry but keep it invisible until stroke support. Flatten ellipses deterministically under a documented error and segment cap.
3. Support nested `<g>` transforms and shape transforms for bounded `matrix`, `translate`, `scale`, and `rotate` forms. Reject skew/invalid syntax until explicitly covered. Apply transforms without mutating source and preserve source offsets in diagnostics.
4. Extend deterministic fixtures and C/Python tests for all supported shapes, nested transform composition, negative/zero dimensions, malformed point lists, NaN/Inf/overflow, singular matrices, cap exhaustion, source retention and byte-identical repeat renders.
5. Compare supported filled fixtures against `rsvg-convert` using a stated pixel/channel tolerance and record renderer version, fixture hashes and mismatch counts. Keep old frozen goldens/oracles unchanged.
6. Make `./dev bench-corpus` a repeatable local command. It must use fresh Vexel processes and existing corpus manifest/hash checks, save raw data under ignored `.cache/M4/`, write `reports/M4/head-to-head.json` and `.md`, and report per-file outcomes plus supported count, first-preview/full-index/max-step/RSS measurements and Inkscape ratios only for comparable successful rows. It must not overwrite M3-06 evidence or rerun Inkscape. Include explicit `--check` mode to validate derived report data.
7. Run the corpus measurement after implementation. Report how many files render and all unsupported/limit/crash rows honestly; do not infer success from feature presence alone.
8. Record Debug/Release sizes and measured benchmark/RSS data with machine/compiler metadata in the JSON report and `docs/PERF.md`; state unavailable metrics explicitly.
