# Existing contracts and invariants
- Apple Silicon macOS 13+ only. No package installation, network use, generated files outside ignored repo-local `.cache/`, arbitrary external-resource loading, or cross-platform code.
- Stress generator uses Python standard library only, explicit seed, checked byte/object/depth/image limits, bounded buffers, streamed writes, deterministic bytes, atomic destination installation, and cleanup on failure.
- Generated SVGs contain no scripts, external URLs, entities, or user/private data. Embedded image profiles use project-authored data only. Output byte targets use decimal 10,000,000 and 100,000,000 bytes; 1,000,000,000 bytes is the hard maximum.
- Golden outputs are project test data (MPL-2.0); record renderer/tool version, license, OS/architecture, renderer-linked component versions, raster dimensions, fixture hashes, and PNG hashes. Do not treat the oracle as an SVG conformance claim or Vexel performance result.
- `rsvg-convert` is an optional local baseline-generation tool, not a build/test dependency. Normal fast tests validate committed oracle hashes offline and do not invoke it.

# Required implementation
1. Add seeded generators for object-heavy, path-heavy, nested-depth, and embedded-image-data SVGs. Expose independent size and semantic controls; reject invalid options before opening outputs; cap nesting, object count, path commands, image payload, and total output at documented values no larger than 1,000,000,000 bytes.
2. Support exact 10,000,000-byte and 100,000,000-byte stress documents plus one deterministic mixed 1,000,000,000-byte document. Stream output with bounded working memory, report bytes/hash/seed/family/counts/elapsed time, and never check generated large documents into Git.
3. Add repeat-generation/hash checks, size and semantic-count tests, invalid/over-limit tests, atomic-write/cleanup tests, and protection against path traversal or overwrite of existing files. Resource-limit failures must leave no partial destination.
4. Render the checked-in M0-01 fixtures at a fixed 256x256 canvas with the installed `rsvg-convert` 2.62.3, retaining compact PNG goldens and an oracle metadata record that pins every source/output hash and records tool/license/environment details. Never render the 1GB input as part of tests.
5. Add offline oracle-lock validation to `./dev test-fast`/macOS CI. Extend `scripts/wo_driver.py` narrowly so only `WO-M0-02` with `baseline: true` may add absent oracle/lock paths during its first baseline commit; test that later work orders, any edit/deletion to a baseline file, root-scope changes, and unrelated frozen files remain rejected. Do not weaken any existing scope checks.
6. Record generation and render measurements in `bench/results/WO-M0-02.json` with exact machine/tool metadata. These measure fixture/oracle generation only; do not claim renderer competitiveness.
