# Goal
Query indexed element bounds by viewport and reuse raster tiles through a deterministic byte-bounded cache with generation and scale invalidation.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/research-r4/05-revised-roadmap.md`, `docs/research-r3/plan/02-architecture.md`, `docs/research-r3/plan/06-benchmark-and-quality.md`, `src/base/README.md`, `src/base/base.h`, `src/svg/index/README.md`, `src/svg/index/index.h`, `src/raster/README.md`, `src/raster/tile.h`, and `src/raster/shape_render.h`.
- Preserve source order for spatial query output so callers can retain painter order. Element bounds and cache keys are supplied by the caller; this work order does not expand SVG shape support.
- macOS-only target: Apple Silicon, macOS 13+, Xcode Apple Clang. Record actual build and machine metadata in benchmark output.
- No external dependencies, network, third-party code, or GPL SVG-editor source.

# Existing contracts and invariants
- C17, checked size arithmetic, pointer+length input, explicit ownership, no VLAs or unsafe string functions.
- Spatial structures and cache are mutable from one owner thread only. No internal threads or UI state.
- Queries use finite axis-aligned bounds and inclusive edge intersection. Output uses the original entry order, independent of tree layout.
- Tile payload ownership transfers only when cache insertion succeeds. Returned cache tiles are borrowed until the next mutating cache call or destruction.
- Cache accounting includes RGBA payload bytes and entry metadata. Eviction must reduce accounted bytes to the configured cap before insertion returns success.
- Generation and integer scale bucket are cache epochs. Changing either clears every entry before subsequent lookup.

# Required implementation
1. Add an immutable packed bounding-volume index for at most 1,000,000 caller-owned records. Reject invalid pointers, non-finite bounds, negative extents, duplicate IDs, arithmetic overflow, and records beyond the documented memory limit before publishing an index.
2. Query viewport intersections into caller storage in original input order. Return the required result count without writing a partial result when capacity is insufficient. Empty query and empty index are valid.
3. Add an opaque raster tile cache with an explicit nonzero byte cap no greater than 256 MiB and a bounded entry count. Use deterministic least-recently-used eviction with stable tie behavior. Reject a tile larger than the cap without taking ownership.
4. Invalidate cache contents when generation or scale bucket changes. A lookup must never return a tile from a prior epoch. Document owner-thread and borrowed/owned lifetimes.
5. Keep query/cache code independent of platform APIs and shape decoding. Add focused boundary, overflow, randomized differential, eviction, ownership, and epoch tests with a fixed seed.
6. Add a deterministic 100,000-record / 1,000-viewport benchmark. Report build time, query p50/p95/max, result counts, build type, binary size, machine/compiler, seed, and cache-cap behavior. Target p95 query time below 5 ms on the named current Mac; report raw values if the target misses.
