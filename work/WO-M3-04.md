# Goal
Deliver a deterministic allocation-free viewer navigation and progress-control model with native pointer/trackpad input, keyboard equivalents, and accessible semantic state.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `docs/research-r4/05-revised-roadmap.md`, `docs/research-r4/02-work-order-template.md`, `docs/ui-test-driver.md`, `src/ui/README.md`, `src/ui/index_progress.h`, `src/platform/platform_window.h`, `src/platform/macos/platform_window.m`, `app/test_driver/README.md`, `tests/ui/README.md`, `tests/ui/native-lifecycle.jsonl`.
- Relevant ADRs: `docs/adr/0001-product-and-platform-locks.md`, `docs/adr/0006-m1-04-owner-quiescence.md`.
- Existing invariants: AppKit calls stay on the main thread; C owns platform handles; pointer coordinates are top-left logical points; dimensions are backing pixels; only current-generation preview tiles may be presented.
- No external sources or dependencies. No SVG parsing, selection/editing, other operating systems, or frozen oracle changes.

# Existing contracts and invariants
- C17, Apple Silicon macOS 13+, custom-drawn UI, and `platform/` boundary only.
- UI state is owner-thread-only. Progress is generation-tagged; canceled, failed, or stale generations cannot show ready state.
- The view transform uses finite values, scale bounds 0.05–64, and preserves the world point beneath the cursor during wheel/pinch zoom.
- Navigation/model update calls do not allocate. Caller-owned output buffers have explicit pointer+length capacity and are never retained.
- All semantic IDs and names are stable and bounded; cancel is exposed only while work is active.

# Required implementation
1. Add an allocation-free owner-thread navigation state API for viewport dimensions, pan, cursor-anchored wheel/pinch zoom, fit-to-document, keyboard pan/zoom/fit, clamped scale, and finite-input rejection. Coordinates and arithmetic must be documented and checked.
2. Extend the macOS window event boundary with bounded scroll and magnification events. Normalize AppKit wheel and trackpad magnify input to finite values, preserve logical top-left cursor coordinates, and add deterministic native test injection for both events.
3. Add a compact custom-drawn progress/cancel overlay into caller-provided RGBA storage. Provide stable semantic snapshots for canvas/zoom, progress percentage and label, and an enabled cancel action while indexing is active. Cancellation is an action request; it cannot itself claim worker termination.
4. Extend the deterministic UI test driver with navigation, progress, cancel, screenshot, and semantic snapshot replay. Keep its input bounded and outputs stable; no wall-clock sleep.
5. Add deterministic screen baseline(s) beneath `tests/ui/navigation-golden/` with a hash-pinned local manifest, plus native event and C-model tests. Exercise 10,000 scene-item projections across at least 100 navigation frames; core frame/navigation calls must make zero heap allocations and match a stable checksum.
6. Add module/test READMEs, exact artifact capture, and update `docs/ui-test-driver.md` and `docs/PERF.md`. Do not edit any protected oracle or baseline.
