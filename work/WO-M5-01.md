# Goal
Add a bounded source-backed document tree with stable document-scoped element handles and deterministic stale-handle rejection.

# Context pointers
- Read: `AGENTS.md`, `OWNER-DIRECTIVES.md`, `STATE.md`, `docs/CODING_STANDARD.md`, `src/document/README.md`, and `src/svg/xml/xml_tokenizer.h`.
- Roadmap: `docs/research-r4/05-revised-roadmap.md`, M5-01.
- Source grammar: the existing project XML tokenizer; preserve all source bytes verbatim.

# Existing contracts and invariants
- C17, macOS only, no new dependency. Source bytes are borrowed and immutable.
- Node handles are values, tied to one document instance and one slot generation. Destroyed documents reject every prior handle. Removed nodes are tombstones and reject their prior handle.
- No pointers into resizable storage escape the API. All source references are pointer+length slices backed by the document's borrowed source lifetime.
- Enforce tokenizer limits and checked allocation arithmetic; no input-sized stack allocation.

# Required implementation
1. Parse a complete XML source through the existing tokenizer into a bounded document-owned node table. Record parent/child/sibling relationships, tag-name source slices, and element source intervals; do not normalize or copy source text.
2. Expose a small public C API for parse/destroy, node count, root, child iteration, tag/source access by handle, and handle removal.
3. Handles contain document identity, slot, and slot generation. Repeated lookup of a live node returns the same handle. Removal increments generation and leaves a tombstone; stale, foreign-document, and malformed handles fail safely.
4. Document identity allocation must detect exhaustion rather than wrap to an existing identity. Node count, token count, and memory arithmetic must be checked and capped by tokenizer defaults.
5. Add module documentation and focused native/Python tests for tree shape, exact slices, stable handles, stale/foreign/malformed handles, empty elements, malformed XML, and allocation/limit failures where deterministic.
