# Goal
Add a C-callable macOS Cocoa window adapter and a scripted native smoke path that creates, resizes, receives normalized events from, and cleanly destroys a window.

Use only public AppKit APIs available on macOS 13+; do not access external SVG-editor source.

# Existing contracts and invariants
- The executable's application logic and public platform interface remain C17. Objective-C is confined to the macOS adapter under `src/platform/macos/`.
- Platform handles are opaque to C callers. Calls that touch AppKit run on the main thread. Event payloads contain logical pointer coordinates, backing pixel dimensions, backing scale, key code/modifiers, and bounded text when present.
- Every owned Objective-C object/resource is released on destroy; poll is non-blocking and reports cleanly when no event is available. Close requests are normalized and do not silently invalidate a C-owned handle.
- Window dimensions are positive and bounded to 4096 logical points per axis; all pixel-size arithmetic is checked. The adapter does not fetch document resources or introduce third-party dependencies.
- Only macOS Apple Silicon is supported; do not add other platform stubs or portability code.

# Required implementation
1. Define a small documented C interface under `src/platform/` for initialization, opaque window creation/destruction, non-blocking event polling, and shutdown. Normalize resize, backing-scale, key down/up, pointer move/down/up, and close-request events.
2. Implement that interface using AppKit only in `src/platform/macos/`. Link the required Apple frameworks via CMake and compile the C application logic as C17; keep Objective-C details out of public headers.
3. Wire a native application mode through the C app composition. The existing Python UI driver must be able to drive a JSONL scenario through open, resize, pointer, key, and quit lifecycle actions, and assert corresponding normalized events and clean closure.
4. Add a native smoke scenario that runs 100 consecutive create/resize/destroy cycles and checks window/event resource cleanup without relying on wall-clock sleeps. Fail with a bounded diagnostic on any missing or malformed event.
5. Document the module contract, event coordinate units, ownership, AppKit main-thread rule, smoke invocation, and the known limitation that synthetic test events do not replace manual device input testing.
