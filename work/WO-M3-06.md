# Existing contracts and invariants
- macOS only, C17, and clean-room source constraints remain in force. Do not inspect or execute any Inkscape source; only run the installed application for missing black-box baseline rows if required.
- The corpus is read-only. Verify every corpus file against its supplied manifest before timing it.
- Each measurement uses a fresh Vexel process and a 120 second timeout. Use three repetitions for T1/T2 and one for T3/T4. Do not rerun Inkscape for rows with baseline values; only fill missing baseline rows once, and never run it on 1 GB inputs.
- The Vexel executable measures first preview, full index and maximum index step when preview is supported. Capture per-process peak RSS on both successful and unsuccessful outcomes.
- Outcomes are exactly `ok`, `unsupported`, `limit`, or `crash`. Unsupported means a completed index with no current-subset preview or a documented unsupported/malformed input; limit means explicit input/resource limit or allocation limit; crash means signal, timeout, or unexplained process failure. Preserve diagnostic evidence and never hide failures.
- Compare Vexel open/index measurements with the supplied Inkscape CLI probe numbers, disclose that the task protocols differ and this is not full-render parity. State the 100 MB preview <2 s / maximum step <100 ms wedge checks and absolute RSS values plainly.
