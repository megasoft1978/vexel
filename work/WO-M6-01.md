# WO-M6-01 — Retained layout, paint, and editor chrome

## Goal
Provide a bounded retained widget tree, deterministic single-pass layout, dark/light design tokens, scalar-rendered paint commands, and a screenshot-golden editor chrome demo.

## Allowed paths
`work/WO-M6-01.md`, `src/ui/**`, `app/ui_*`, `tests/ui/**`, `tests/test_ui_chrome_golden.py`, `CMakeLists.txt`, `STATE-laneB.md`, `LEDGER-laneB.md`, `docs/ui/**`, `bench/results/WO-M6-01.json`, `docs/PERF.md`.

## Acceptance
- A fixed-capacity retained tree has stable IDs, bounded depth, deterministic flex/fixed layout, and rejects invalid/duplicate/capacity-overflow nodes.
- Theme tokens are complete for dark and light themes; demo includes toolbar, tool palette, canvas, properties inspector, and status bar.
- Flat node fills render through the public scalar SVG shape API using fixed-size scratch, independent of viewport area; output is deterministic.
- Dark/light 1280x800 screenshots match hash-pinned goldens; UI core tests pass.
- `./dev verify`, Debug/Release builds, and ASan/UBSan CTest pass.
