# vexel-svg-decode

Same frozen WO-RUST-SVG-DECODE-01 R2 candidate, continued from the exact accepted
Scene177 initialization and explicit-channel R3 seed. Not complete or accepted.

`Decoder::from_source` borrows canonical LexicalDocument/DecodeSource and owns its
SceneBuilder, draft stack and source-only tasks. Inherited styles/currentColor,
marker clearing, transforms/viewports, switches, local use/symbol expansion,
geometry/path/custom publication, host maps, groups, ignored diagnostics, typed
lower plans and nested pattern suspension execute through the real scene APIs.
Numeric loops and transfers charge work. DecodeQuantum provides soft atomic
boundaries with actual overshoot; it promises no fixed execution latency.

## Production composition

Use `step_production(quantum, operations, &job, control)`. Required
`DecoderProductionOperations` combines accepted CachedPaintResolver,
DefinitionPlanner, PaintChannelDefinitionPlanner and media interfaces with scoped
media callbacks. Pattern planning always receives explicit Fill or Stroke;
nonpaint dispatch uses the accepted combined planner. Owner lexical anchor and
resolved definition remain independent. No span or channel equality inference.
Cached stops are published directly from the resolver's borrowed template.

The builder starts provisional. Canonical root initialization follows original
attribute/style/display and visible-transform checks. A hidden root has no
viewport. All traversal reads use TraversalView. Actual same-source animation is
parsed once after successful root traversal, then installed with checked ownership,
generation and capacities. `finish_decoded` returns actual HiddenScene or Drawable;
`finish` remains drawable-only compatibility.

`TraversalDecodeEvent::NeedPattern` carries a real sealed child, honest optional
animation and single-use mapped ticket. Retain the same RasterJob, end the view
borrow, and call `resume_pattern_production` with actual JobRenderOutput. Failure
rolls back; nested children complete before their parent. Rendering a static child
while parent animation is pending still needs the coordinator timing boundary.
Test render outputs are explicit fixtures, not production render implementations.

Scoped media callbacks borrow the actual active DraftToken inside an engine-owned
request transaction. They can use `admit_text_commands`; success validates and
commits, failure unconditionally rolls back. Real native providers and adapters
must be supplied downstream; no defaults or fake production providers exist.

The older `step`/DecodeOperations/raw Tile route remains explicit compatibility.
Its ready PatternRequest cannot represent pending animation; use additive
`step_traversal` for explicit legacy fixtures. Seven original assertions and all
smooth-path predicates remain unchanged. Hidden helper tests inspect the actual
hidden outcome without fabricating a drawable viewport.

Fallible actual-capacity leases cover initial tables, plans, active/task/child-draft
stacks, overlap and temporary clip copies. `lease_stats` exposes the decoder journal
by value; builder accounting is separate. Neither claims RSS or one aggregate
renderer allocation budget. No source reparse/clone or dependency change.

## Remaining evidence

The overlapping post-Z path under use still fails the shared canonical source-range
validator. Shape pregeometry admission and cache-generation followups are not seeded.
The registered media/definitions crates contain no real adapters, and the frozen
manifest lacks tile-cache test access. The 512-use probe bounds now run through
the actual Decoder traversal and inspect the accepted
`DecodeSource::reference_lookup_probes()` value. Decoder lease history is
available through `lease_allocation_history()` and records the accepted
`ChargeLedger::allocation_history()` snapshot; actual reference-index capacity
is checked against `DecodeSource::reference_storage_bytes()`. Nested group range
publication is also checked after real Decoder traversal. The 4096-comment/
512-shape paint-token visit predicate still uses the explicit lower resolver
fixture, so it is not evidence for the accepted production paint resolver.
Exact clip-chain source-span/capacity history, the renderer's 256-byte output
predicate, aggregate job accounting, and mixed renderer/CLI/oracle proofs remain.
The definitions and tile-cache gates need their accepted packages in a
coordinator-owned harness; this crate does not shadow those implementations.
See own `initialization-resume/accepted-contract-blockers.md` and full parity,
coverage and verification reports. Independent root review/audit/main checks are
mandatory before acceptance.
